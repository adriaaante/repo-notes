# Набор для Яндекс Бизнеса — образец генератора (раздел 4 SKILL.md)

Рабочая копия генератора FutureFlow (`adriaaante/futureflow-site`, `deploy/yandex/`, 04.11.2026).
В новый проект копируется в `deploy/yandex/` и правится под бренд клиента. Сами файлы здесь
не запускать: пути внутри считаются от корня репозитория проекта.

| Файл | Что это | Что менять под проект |
|---|---|---|
| `kit.mjs` | ВСЕ тексты, лимиты Яндекса, прайс, истории, публикации, акции, ролики, отзывы — единственный источник | Целиком: это пример FutureFlow. `LIMITS` оставить как есть |
| `build.mjs` | Рендер картинок (Playwright), роликов (ffmpeg), фида YML, страницы `/otzyv/`, проверка лимитов и повторов фонов | Блок «бренд» (откуда брать знак и надпись логотипа), цвета в `BASE`, шрифты, пути `OUT`/фида, имена файлов `futureflow-*`, тексты `/otzyv/`, источник логотипа-плитки |
| `page.mjs` | Страница скачивания (noindex, кнопки «Копировать», счётчики против лимитов) | Путь страницы (по умолчанию — вне сайта, см. раздел 4), название бренда |
| `qr.py` | Матрица QR (коррекция H — выдерживает знак в центре) | Ничего. `pip install qrcode` |

Запуск в песочнице: `NODE_PATH=$(npm root -g) node deploy/yandex/build.mjs` (`--no-video` — не
пересобирать ролики). Фоны — `deploy/yandex/bg/<имя>.jpg`, клипы — `deploy/yandex/clips/<имя>.mp4`.
