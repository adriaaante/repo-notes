# repo-notes — единый скилл Claude Code для проектов FutureFlow

Один скилл `.claude/skills/repo-notes`, команда `/repo-notes`. В нём всё:

| Часть | Что |
|---|---|
| 1. Правила поведения | Искать лучший вариант, не плодить лишнее, убирать за собой, «готово» = проверено |
| 2. Память проекта | Что и как вести в `CLAUDE.md` каждого репозитория |
| 3. Клиентские проекты FutureFlow | Реквизиты Исполнителя, счета (QR + логотип), договоры, акты, допсоглашения, сквозная нумерация по клиенту, журналы `finance-log` / `promo-log`, отчёты, аудиты и КП в PDF в фирменном стиле |

Файлы скилла: `assets/` (логотип PNG для docx и SVG для PDF, шрифт Manrope), `docs/` (генераторы docx,
QR, проверка готового файла, нумерация, реестр префиксов клиентов), `templates/` (журналы, шаблон отчёта),
`scripts/build-pdf.sh`.

**Логотип FutureFlow** — `assets/futureflow-logo.png`, первым абзацем документа по правому краю,
ровно 24,6 × 5,3 мм, синий. Один и тот же файл и размер во всех документах: счёт, договор, акт, допсоглашение, отчёты и КП в PDF. Подробно — SKILL.md, раздел 3.0; проверяет `docs/check-docx.py`.

## Как подключить

- **Во всех облачных сессиях.** Вставить `claude-code-environment-setup-repo-notes.sh` целиком в
  claude.ai/code → окружение → Setup script (заменить прежний). При старте контейнера скилл ставится в
  `~/.claude/skills/repo-notes` из ветки `main`; старый отдельный скилл `futureflow` удаляется.
- **В аккаунт Claude.** Загрузить `repo-notes-skill.zip` в claude.ai → Настройки → Возможности → Skills.
- **В один репозиторий.** Скопировать папку `.claude/skills/repo-notes` в `.claude/skills/` проекта.

## Правка скилла

Правим файлы в `.claude/skills/repo-notes/`, затем `python3 make-setup-script.py` (пересобирает
setup-скрипт и zip) и коммит в `main`. Облачные сессии подхватывают файлы из `main` при следующем старте;
сам текст setup-скрипта в настройках окружения нужно заменить, только если изменился `make-setup-script.py`.
