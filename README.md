# repo-notes — скиллы Claude Code для проектов FutureFlow

| Скилл | Для чего |
|---|---|
| `.claude/skills/repo-notes` | Правила работы с любым репозиторием и память проекта в `CLAUDE.md` |
| `.claude/skills/futureflow` | Деньги, документы и отчётность клиентских проектов: реквизиты Исполнителя, счета с QR, акты, допсоглашения, журналы `finance-log` и `promo-log`, отчёты и КП в PDF с логотипом FutureFlow. Плюс порядок записи решений владельца, граблей и уроков в `CLAUDE.md` проекта. Всё по практике проекта «Сферикс» |

## Как подключить к проекту

- **Во всех облачных сессиях сразу.** Вставить `claude-code-environment-setup-repo-notes.sh` целиком в
  claude.ai/code → окружение → Setup script. При старте контейнера оба скилла кладутся в
  `~/.claude/skills`, команды `/repo-notes` и `/futureflow` работают в любом репозитории.
- **В один конкретный репозиторий.** Скопировать папку `.claude/skills/futureflow` в `.claude/skills/`
  проекта и закоммитить. Или сказать Claude в сессии проекта: «установи скилл futureflow из
  adriaaante/repo-notes».
- **В аккаунт Claude.** Скачать `futureflow-skill.zip` (или папку `.claude/skills/futureflow` архивом) и загрузить в claude.ai → Настройки → Возможности → Skills → «Загрузить скилл».

## Первый запуск в новом клиентском проекте

Сказать «заведи журналы и документы FutureFlow для <заказчик>»: скилл развернёт `_materials/`
(журналы, логотип, шрифт, генераторы), попросит реквизиты заказчика в `client.json` и префикс счетов.

Правка скилла — здесь, коммитом; в проекты и в окружение она приходит при следующем старте сессии.
